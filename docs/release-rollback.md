# Откат релиза

У семей на телефонах стоит приложение, которым они пользуются в 7 утра.
Плохая версия обнаруживается именно тогда — когда её уже нельзя чинить
спокойно. Значит, откат должен занимать минуты и не требовать решений.

## Что всегда под рукой

**Предыдущий APK.** Каждая сборка CI сохраняет артефакты; кроме того,
перед выкладкой новой версии предыдущая кладётся на страницу раздачи
рядом с новой:

```
/apk/child-parent-latest.apk      ← текущая
/apk/child-parent-previous.apk    ← предыдущая, всегда
/apk/child-driver-latest.apk
/apk/child-driver-previous.apk
```

Откат приложения = поменять местами две ссылки и сказать диспетчеру,
чтобы просил ставить `previous`. Плюс раздать ссылку водителям — их
пять-десять человек, это десять минут.

**Предыдущий образ сервера.** Каталог релиза помечается версией, старый
не удаляется:

```bash
/opt/child/releases/0.1.0/
/opt/child/releases/0.2.0/
/opt/child/current -> releases/0.2.0
```

Откат сервера:

```bash
ln -sfn /opt/child/releases/0.1.0 /opt/child/current
systemctl restart child
```

## Порядок выкладки — такой, чтобы откат был возможен

1. **Миграции только совместимые вперёд.** Новая колонка — добавляется
   с `default`, старая — не удаляется в том же релизе, а помечается
   неиспользуемой и удаляется через релиз. Тогда откат сервера не
   требует отката базы: старый код просто не знает про новую колонку.
2. **Бэкап перед выкладкой** — обязательно (`tools/backup_db.sh`),
   даже если миграций нет.
3. **Сначала сервер, потом приложения.** Сервер умеет отвечать старым
   приложениям, наоборот — нет.
4. **Выкладка не в 7 утра и не в пятницу вечером.** Лучшее время —
   после 15:00 в будний день: дневные рейсы закончились, до утра есть
   ночь на исправление.

## Когда откатывать, не раздумывая

- перестали уходить уведомления (видно по мониторингу);
- события поездок не принимаются или задваиваются;
- ошибка в деньгах: двойное списание, неверный баланс;
- приложение водителя не открывает экран поездки.

Во всех этих случаях откат дешевле разбирательства: разбираться можно
после, когда дети уже доехали.

## Что делать сразу после отката

1. Сказать диспетчеру, что версия старая — что работает, что нет.
2. Проверить книгу операций за день: если сбой был в деньгах, записи
   исправляются **новой корректирующей записью с причиной**, а не
   правкой старых (книга только дописывается).
3. Прогнать `./tools/rehearsal.sh` на исправленной версии до следующей
   выкладки — он проходит полный день, включая деньги и эскалацию.
