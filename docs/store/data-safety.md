# Форма Data Safety в Google Play

Ответы для анкеты. Отвечаем честно: заявить меньше, чем собираем, —
верный способ получить блокировку приложения, которым пользуются семьи.

## Ключевые ответы

- **Шифруется ли передача?** Да, весь трафик по HTTPS/WSS.
- **Можно ли запросить удаление данных?** Да, через диспетчера; описано
  в политике конфиденциальности.
- **Собираются ли данные детей?** Да. Приложением пользуются родители;
  у ребёнка нет аккаунта. Данные о ребёнке вносит родитель.
- **Используются ли данные для рекламы?** Нет.
- **Передаются ли данные для аналитики?** Нет.

## Отдельно про местоположение

Google требует объяснить фоновый доступ к геолокации. Наш ответ:
местоположение пишется **только во время активной поездки** — от «выехал»
до «передал», с видимым уведомлением в шторке. Вне поездки приложение
координаты не запрашивает. Трек хранится 30 дней.

Это ровно тот случай, когда фоновая геолокация оправдана: родитель
должен видеть, где машина с его ребёнком. В описании для проверяющего
нужно показать видео этого сценария — Google этого требует.
