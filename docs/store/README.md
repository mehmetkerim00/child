# Тексты для Google Play

Готовы к публикации, но **не опубликованы**: нужен аккаунт разработчика
и финальное решение по бренду.

| Файл | Что внутри |
|---|---|
| `listing-ru.md`, `listing-tk.md`, `listing-en.md` | название, краткое и полное описание |
| `privacy-ru.md`, `privacy-tk.md`, `privacy-en.md` | политика конфиденциальности |
| `data-safety.md` | ответы на форму Data Safety |

## Перед публикацией

1. **Политику нужно выложить по публичному адресу** — Google Play
   требует ссылку, а не файл. Планируется
   `https://sagaman.tm/privacy` (ru), `/privacy/tk`, `/privacy/en`.
2. **Скриншоты** (минимум 2 на язык) и feature graphic 1024×500 —
   нужен дизайнер.
3. **applicationId менять нельзя** после первой публикации:
   `com.sagaman.parent` и `com.sagaman.driver`.
4. Приложение водителя публикуется **закрытым треком**: оно не для
   широкой аудитории, а для нанятых водителей.

## Чего в описании намеренно нет

Обещаний «безопасно на 100%» и слова «гарантия». Сервис возит детей; в
тексте, который читает родитель, нельзя обещать того, чего никакая
система дать не может. Описан протокол — кодовое слово, передача из рук
в руки, SMS без интернета, — а выводы родитель делает сам.
